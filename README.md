# Simple Interest Calculator

A lightweight Bash calculator that computes **simple interest** based on the principal, annual interest rate and time period.

## Inputs

- **Principal (P):** Initial amount of money.
- **Rate (R):** Annual interest rate, expressed as a percentage.
- **Time (T):** Investment or loan duration in years.

## Formula

For a rate expressed as a percentage:

```text
Simple Interest = P × R × T / 100
```

## Run

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Example:

```text
Enter principal amount: 1000
Enter annual interest rate (%): 5
Enter time period (years): 2
Simple Interest: 100.00
```
