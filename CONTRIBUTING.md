# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue to describe the proposed change, report a bug, or suggest an improvement.
2. Fork the repository and create a descriptively named branch from `main`.
3. Make a focused change, with a clear commit message.
4. Test the Bash calculator with normal, decimal and invalid inputs.
5. Open a pull request describing the change, how it was tested, and related issue references.

## Development and testing

```bash
bash -n simple-interest.sh
printf '1000\n5\n2\n' | bash simple-interest.sh
```

Expected output for the example is `Simple Interest: 100.00`.

## Community standards

Please follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Contributions are reviewed for clarity, correctness and maintainability.
