# Code of Conduct

## Our Pledge

We pledge to make participation in this project a welcoming and harassment-free experience for all contributors, regardless of background, identity, experience, or personal characteristics.

## Our Standards

Positive behavior includes using respectful language, welcoming constructive feedback, documenting decisions clearly, and prioritizing the safety and well-being of other participants.

Unacceptable behavior includes harassment, hateful or discriminatory remarks, bullying, threats, publication of private information without permission, and sustained disruption of project discussions.

## Enforcement Responsibilities

Project maintainers are responsible for explaining community standards, addressing reports fairly, and applying appropriate and proportionate consequences. Reports should be treated confidentially to the extent possible.

## Scope

This Code of Conduct applies to repository discussions, issues, pull requests, code reviews, project-related events, and public interactions in which a person is representing this project.

## Enforcement

Report concerns privately to the repository maintainers using GitHub's available contact or reporting mechanism. Include relevant links, dates and context when possible. Do not publish sensitive personal details in a public issue.

Maintainers will review reports promptly and protect reporting participants from retaliation. When a report concerns a maintainer, seek an independent maintainer or GitHub platform support.

## Enforcement Guidelines

1. **Correction:** For minor, unintentional issues, provide private or public guidance and request a correction.
2. **Warning:** For repeated or more serious behavior, issue a formal warning and establish boundaries.
3. **Temporary restriction:** For continuing violations, restrict participation in project spaces for a specified period.
4. **Permanent ban:** For severe, threatening or persistent violations, permanently remove project participation privileges where possible.

Enforcement decisions will consider the safety of affected people, evidence available, and opportunities for responsible remediation.

## Attribution

This Code of Conduct draws on the general principles of the Contributor Covenant and is customized for this educational project. See [Contributor Covenant](https://www.contributor-covenant.org/) for additional background.
